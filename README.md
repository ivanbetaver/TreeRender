# TreeRender: Тестовое задание  разработчика
================================

Вводные выдываемые кандидату до получения задания
----------------------------------------------------

* На тестовое задание отводится не более трех часов. Ожидаемое время выполнения - от 1.5 до 3 часов.
* Кандидату необходимо иметь окружение позволяющее выполнить тестовое задание по написанию простого консольного приложения использующего файловый ввод/вывод  и работу с аргументами командной строки. Требования: JavaSE 11 (single-file source-code Java SE приложение).
* Задание направлено _скорее_ на проверку общих базовых навыков в области программмирования, нежели на предметные или углубленные знания и способности из backend стека

Требования
-----------------

* Язык и SDK: Java SE 11 или любой из списка: NodeJs (JavaScript/TypeScript), Python 3.9.
Задание оформлено для Java, однако если вы выбрали другой язык вам необходимо приложить readme.md файл в котором привести свою строку запуска приложения из консоли с двумя параметрами %INPUT_FILE_NAME% и %OUTPUT_FILE_NAME%.
* Исходный код проекта упаковать в архив 'КодВакансии_КодЗадания_ФИО_Дата.zip', пример `as-fs-02_02_Ivanov-Ivan-Ivanovich_2023-02-02.zip`. Код вакансии расположен внизу вакансии в сервисе hh.ru.

Задание
---------

Написать консольное приложение `TreeRender`:

1. Приложение обязано быть  Single-file source-code Java SE приложением;
2. Приложением должно принимать на вход два параметра и запускаться командой: `java --source 11 TreeRender.java %INPUT_FILE_NAME% %OUTPUT_FILE_NAME%`;
3. Читать текстовый файл `%INPUT_FILE_NAME%`. В файле содержится текстовое определение дерева, в качестве узлов натуральные числа. Анализ формата записи выполнить самостоятельно по приведённому  примеру:

    ```txt
    (1 (2 (4 5 6 (7) 108 (9)) 3))
    ```

4. Результатом выполнения программы должен быть файл записанный по пути `%OUTPUT_FILE_NAME%`. Файл должен содержать псевдо-графическую текстовую визуализацию дерева. Для ввода приведенного выше должен быть следующий вывод:

    ```txt
    1---+
        2---+
        |   4
        |   5
        |   6-----+
        |   |     7
        |   108---+
        |         9
        3
    ```

Ожидания от программы в порядке важности
------------------------------------------

1. **Работающая программа** в соответствие  с ТЗ: на правильный ввод программа `TreeRender` выдает ожидаемый вывод без ошибок (Проверка нами работоспособности программы выполняется автоматизировано). 
2. Читаемость кода: лаконичность, соответствие  стандартам оформления, практикам документирования

Бонусно, положительно может быть оценено:

1. Обработка ошибок, в том числе неправильного ввода-вывода
2. Тесты
3. Оптимизация и эффективность работы приложения
